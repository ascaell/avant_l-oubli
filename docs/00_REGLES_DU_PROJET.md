# RÈGLES DU SUJET

Source : sujet officiel JAM RPG.

Le jeu doit respecter :
1. Interface agréable et compréhensible.
2. Univers cohérent.
3. Jeu amusant avec un objectif clair.
4. Début et fin : pas une démo sans issue.

Les huit obligatoires et le cœur technique sont détaillés dans README.md.

⚠️ Limite dure : 30 Mo.
⚠️ MUST avant SHOULD avant COULD.
⚠️ Chacun doit être capable d'expliquer sa partie à la défense.
