# MONDE ET PNJ

## Village de départ
Le village n'est jamais vide.

PNJ :
- Ancien : histoire
- Garde : tutoriel combat
- Guérisseur : soins
- Forgeron : équipement
- Fermier : première quête
- Enfant : informations / ambiance
- Chef : quête principale
- Mystérieux : lien avec le voyage temporel

## Zones
1. Village
2. Territoire extérieur / forêt
3. Forteresse ennemie
4. Zone finale

Chaque zone peut exister dans le passé et dans le futur avec des différences visuelles et gameplay.

## Règle
Peu de PNJ, mais chacun doit avoir une fonction claire.
