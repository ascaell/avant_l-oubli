# WORKFLOW ÉQUIPE

## Chaque membre
1. `git clone URL_DU_REPO`
2. `cd avant-l-oubli`
3. `git checkout dev`
4. `git pull origin dev`
5. créer sa branche
6. travailler
7. commit clair
8. push de sa branche
9. Pull Request vers `dev`

## Nommage
feature/player
feature/combat
feature/world
feature/ui
feature/story

## Commits
feat: ajout du déplacement
fix: correction collision
ui: ajout menu pause
story: ajout dialogue village
docs: mise à jour roadmap

## Interdit
- push direct sur main
- gros commit incompréhensible
- ajouter une feature sans vérifier TODO/roadmap
- modifier la partie d'un autre sans prévenir

## Pull Request
Chaque PR doit expliquer :
- ce qui a été fait
- comment tester
- fichiers importants
- éventuels problèmes
