# HISTOIRE

## Acte I — Le monde qui a oublié
Flowflow commence dans un village du futur, marqué par les conséquences d'une ancienne conquête.
Le village sert de tutoriel.
Les PNJ expliquent progressivement le monde, les contrôles et le passé.

## Acte II — Le temps des ancêtres
Flowflow utilise l'instrument ancestral pour retourner dans le passé.
Le royaume est encore vivant.
Une puissance étrangère commence à imposer son influence.
Les conflits internes rendent la conquête possible.

## Acte III — Avant l'oubli
Flowflow atteint l'événement historique décisif.
Il doit accomplir sa quête et accepter les conséquences de ses choix.

## Fin
Le jeu doit afficher une vraie conclusion.
Les choix du joueur peuvent modifier le futur final.

Les détails narratifs sont ouverts aux propositions dans IDEAS.md.
