# AVANT L’OUBLI — Identité visuelle

## 1. Direction artistique

Style général :
- RPG 2D isométrique / pixel art
- Univers sérieux, mystérieux et émotionnel
- Inspiration visuelle : Afrique ancienne + science-fiction post-apocalyptique
- Décors détaillés mais lisibles
- Contraste clair entre le passé et le futur

Le jeu doit rester cohérent entre :
- personnages
- décors
- interfaces
- effets
- textes
- sons

---

---

## 3. Contraste passé / futur

Le même lieu peut exister dans les deux époques.

PASSÉ :
- couleurs chaudes
- végétation
- bâtiments entretenus
- population présente
- lumière naturelle

FUTUR :
- couleurs froides
- ruines
- végétation morte
- bâtiments détruits
- brouillard / poussière
- lumière faible

Le joueur doit pouvoir comprendre l'époque uniquement grâce à l'ambiance visuelle.

---

## 4. Personnage principal — Flowflow

Flowflow doit être immédiatement reconnaissable.

Caractéristiques visuelles :
- silhouette simple et identifiable
- vêtements inspirés de son peuple
- éléments rappelant son héritage
- instrument ancestral facilement identifiable
- palette cohérente avec le monde

Son design doit fonctionner même à petite résolution.

---

## 5. Ennemis

Les ennemis doivent être différenciables par leur silhouette.

Types :
- Soldat
- Éclaireur
- Combattant lourd
- Officier
- Collaborateur
- Boss

Chaque type doit avoir :
- une silhouette différente
- une couleur/accent distinct
- une animation identifiable

---

## 6. Interface

L'interface doit rester simple et lisible.

### Boutons

Chaque bouton possède au minimum 3 états :
1. Normal
2. Survolé
3. Pressé

Les états doivent être clairement visibles.

### Style

- formes simples
- bordures légèrement marquées
- peu de couleurs
- typographie lisible
- aucun élément décoratif inutile

L'interface doit appartenir au même univers que le jeu.

---

## 7. Typographie

Utiliser au maximum :
- 1 police principale pour l'interface
- 1 police secondaire uniquement si nécessaire

Priorité :
- lisibilité
- cohérence
- rendu RPG

Les textes importants doivent être facilement lisibles pendant le gameplay.

---

## 8. Maps

Les maps doivent respecter une logique isométrique.

Éléments :
- sol
- murs
- bâtiments
- végétation
- obstacles
- éléments interactifs

Les éléments importants doivent rester visibles malgré la perspective.

---

## 9. Effets

Les effets doivent respecter la direction artistique.

Exemples :
- attaque
- impact
- transition temporelle
- interaction avec l'instrument
- changement passé/futur

Éviter les effets trop modernes ou trop flashy qui casseraient l'ambiance.

---

## 10. Audio

L'audio doit renforcer la différence entre les deux époques.

Passé :
- ambiance naturelle
- percussions
- instruments traditionnels
- environnement vivant

Futur :
- ambiance plus silencieuse
- sons sourds
- vent
- ruines
- effets plus froids

Les musiques et sons doivent rester cohérents avec l'univers.

---

## 11. Règle importante

Aucun membre ne doit introduire :
- une nouvelle palette sans validation
- une nouvelle police sans validation
- un style graphique complètement différent
- des éléments visuels qui cassent l'univers

En cas de doute :
→ demander avant d'intégrer.

---

## 12. Objectif

Le joueur doit reconnaître immédiatement :

AVANT L'OUBLI

et comprendre visuellement la différence entre :

LE PASSÉ → vivant, chaud, ancestral

LE FUTUR → froid, détruit, oublié
