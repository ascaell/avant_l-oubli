# 💡 IDEAS — BOÎTE À IDÉES

Tout le monde peut proposer une idée ici.

## Format

### [IDÉE] Nom
**Auteur :**
**Catégorie :** Gameplay / Histoire / PNJ / UI / Technique / Audio / Visuel
**Description :**
**Pourquoi c'est intéressant :**
**Impact sur le temps :** faible / moyen / fort
**Impact sur la taille :** faible / moyen / fort
**Priorité proposée :** MUST / SHOULD / COULD

## Statuts
🟡 À discuter
🟢 Validée
🔴 Refusée
🔵 En attente

## Règle
Une idée n'est pas automatiquement développée.
On vérifie d'abord :
1. sujet
2. faisabilité
3. temps
4. taille du dépôt
5. valeur pour le jeu

## Exemple

### [IDÉE] Le village change après une action temporelle
**Auteur :** exemple
**Catégorie :** Histoire
**Description :** un PNJ change de dialogue dans le futur si Flowflow l'aide dans le passé.
**Pourquoi :** renforce le concept temporel.
**Impact temps :** moyen
**Impact taille :** faible
**Priorité :** SHOULD
**Statut :** 🟡 À discuter
